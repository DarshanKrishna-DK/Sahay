# Landing figures: output contract

Two isometric "anatomy" figures live on the landing page (`/`): `balance` (bargaining balance,
track FIG) and `printer` (receipt printer with a YES stamp, track FIG2). Both follow this
contract so the landing can mount either one the same way. Built with the anatomy skill
(`~/.claude/skills/anatomy`); the kit is MIT (`scripts/figures/kit/LICENSE`).

## Ownership
| Path | Owner |
|---|---|
| `public/figures/<name>/*`, `scripts/figures/<name>/*` | that figure's track (`balance`: FIG, `printer`: FIG2) |
| `public/figures/figures.css`, `iso-kit.js`, `loader.js`, `preview.html`, `preview.js`, `README.md`, `scripts/figures/kit/*`, `scripts/figures/common.mjs`, `scripts/figures/build.mjs` | FIG (ask before changing) |
| `public/index.html`, `public/css/landing.css`, `public/js/landing/*` | FIG (embedding is done there) |

## Files each figure emits (`public/figures/<name>/`)
| File | What |
|---|---|
| `<name>.svg` | The static art as an SVG fragment: `<svg class="iso-svg" viewBox="0 0 600 H" role="img" aria-label="…">`, no `<style>`, no `<script>`, no inline colours (every fill and stroke comes from the kit classes `iso-fill`, `iso-shade`, `iso-top`, `iso-line[data-tone]`, `iso-dots`, `tb-*`). Drawn in the **still pose**: the end state that explains the idea (reduced motion and the first paint show it). Moving parts are groups/paths with `data-part="…"`. Width 600, height 420 to 500, size under 250 KB. |
| `live.js` | ES module, the only code the page runs for the figure. Imports only `../iso-kit.js`, `./model.js`, `./geo.js` (relative paths). Exports `mount` and `META` (below). |
| `model.js` | Pure model (no DOM): the numbers the motion, the readout and the tests share. |
| `geo.js` | Generated by the build: `export const GEO = {…}` (projection `P`, anchors). |
| `<name>.css` | Optional extra rules, scoped under `.iso-figure[data-figure="<name>"]`, tokens only. The loader links it if `META.css` is true. |

Builds are Node ES modules: `scripts/figures/<name>/build.mjs`, run by `node scripts/figures/build.mjs` (runs every figure). Import the kit from `../kit/iso-kit.mjs` and `../kit/lathe.mjs`; load the browser model with `importBrowserModule("<name>/model.js")` from `../common.mjs` (public JS is ESM inside a CommonJS package).

## `live.js` interface
```js
export const META = {
  fig: 2,                                  // "Fig 2" in the top-left corner
  css: false,                              // true: the loader links ./<name>.css first
  words: {                                 // every visible word, en / hi (Devanagari) / kn (Kannada script)
    title:   { en, hi, kn },               // top-right corner, 1 to 3 words
    hint:    { en, hi, kn },               // bottom-left: how to interact, e.g. "Press the stamp"
    caption: { en, hi, kn },               // one or two true sentences under the card
    label:   { en, hi, kn },               // aria-label of the focusable stage
    // plus any keys your readout uses
  },
};
export function mount(stage, { readout, lang, reduced }) {
  // stage:   the focusable <div class="iso-stage"> that already holds the inline <svg>
  // readout: the bottom-right corner element; write readout.textContent from the model
  // lang:    "en" | "hi" | "kn";  reduced: true when prefers-reduced-motion is set
  // Draw the current pose synchronously. Do not start a frame loop until play().
  return {
    play(),            // start or resume the loop (the loader calls it when on screen and motion is allowed)
    pause(),           // stop the loop (off screen, tab hidden)
    setReduced(bool),  // true: jump to the still pose, no loop, no tour; input still works (jumps, no easing)
    setLanguage(lang), // rewrite the readout and aria texts
    destroy(),
  };
}
```
Rules: time-based motion (dt clamped to 1/30 s), eased or sprung, never snapping; an idle tour
that the pointer or keyboard takes over and that resumes about 3.6 s after the last input;
keyboard on the stage (arrows / Home / End / Space or Enter as fits); `aria-valuetext` written
only on discrete changes, never per frame; the readout is short, in the reader's language,
read from where the parts are. No `console` output, no timers left running after `pause()`.

## How the landing mounts a figure
Markup (in `public/index.html`, written by FIG):
```html
<figure class="iso-figure fig-card" data-figure="printer" data-state="idle">
  <div class="iso-plate">
    <div class="iso-plate-corners"> fig / title / hint / readout corners </div>
    <div class="iso-stage" tabindex="0" role="slider|group" aria-label="…"></div>
    <p class="fig-status"> loading or error text </p>
  </div>
  <figcaption class="iso-legend">…</figcaption>
</figure>
```
`public/figures/loader.js` (`mountFigures(root, { lang, reducedQuery })`):
1. Waits until the card is within 600 px of the viewport (lazy). `data-state="loading"`.
2. Links `<name>.css` if `META.css`, fetches `<name>.svg`, puts it in the stage, imports `live.js`, calls `mount`.
3. `data-state="ready"`; on any failure `data-state="error"` and a written error message (no fallback art).
4. Calls `play()` while the card is on screen, the tab is visible and motion is allowed; `pause()` otherwise; `setReduced()` when the media query changes. It mirrors this as `data-motion="playing|paused|still"` on the figure.
5. Re-labels on the `landing:language` event via `setLanguage()`.

## Themes and tokens
`public/figures/figures.css` maps the kit tokens (`--anatomy-*`) to Sahay v3: dark (the landing
is dark only); a light set exists only under an explicit `:root[data-theme="light"]` (the preview
page). The one lit accent (`--anatomy-lit`, data-lit solids, `data-tone="lit"` lines) is
creamy pink (#F2CFC6) on warm blacks with cream lines; the landing is dark only. Never type a colour into SVG or JS.

## Checking a figure
Run a scratch server from your worktree (`PORT=39xx DB_FILE=<scratch>.db node server.js`) and open
`/figures/preview.html?fig=<name>&theme=dark|light` (same loader as the landing). Headless only,
one capture run at a time, with the anatomy skill's `scripts/capture.mjs` / `drive.mjs` /
`lines.mjs` (select `.iso-plate`). Evidence goes to `docs/build/evidence/fig-*.png`.
